## Purpose

Определяет, какие сведения о пользователе разрешено добавлять в AI-контекст и возвращать через tools, чтобы упоминание или участие в одном чате не открывало личные данные из других чатов.

## ADDED Requirements

### Requirement: Персональные данные имеют явную область видимости

Система MUST добавлять в AI-контекст текущего запроса глобальные личные факты и память только текущего отправителя. Для другого пользователя система MUST NOT добавлять личную память и MUST включать только те факты, для которых существует подтверждённый публичный источник в текущем чате. Общая память чата MUST выбираться только по идентификатору текущего чата.

#### Scenario: Текущий пользователь продолжает личный диалог

- **WHEN** система формирует AI-контекст для сообщения текущего пользователя
- **THEN** она может использовать личную память и факты этого пользователя согласно действующим правилам private mode

#### Scenario: В сообщении упомянут другой пользователь

- **WHEN** текст содержит `@username` или `text_mention` другого пользователя
- **THEN** личная память этого пользователя и факты без публичного источника в текущем чате не попадают в AI-контекст

#### Scenario: В текущем чате есть подтверждённый публичный факт

- **WHEN** факт другого участника подтверждён публичным сообщением этого участника в текущем чате
- **THEN** система может включить этот факт без данных из иных источников и чатов

#### Scenario: Загружается общая память чата

- **WHEN** система добавляет shared memory в AI-контекст
- **THEN** выбираются только записи текущего чата

### Requirement: Запрос сведений о другом пользователе требует текущего участия

Система MUST подтверждать через Telegram, что запрошенный пользователь сейчас является участником текущей группы. Историческое сообщение, глобальный username или известный ID MUST NOT считаться достаточным подтверждением. При невозможности подтвердить участие система MUST отказать без раскрытия персональных данных.

#### Scenario: Запрошен текущий участник группы

- **WHEN** Telegram подтверждает, что другой пользователь сейчас состоит в текущей группе
- **THEN** tool возвращает базовый профиль и только факты с публичным источником в этой группе без личной памяти

#### Scenario: Пользователь покинул группу

- **WHEN** в базе осталось его сообщение, но Telegram сообщает, что пользователь больше не участник
- **THEN** tool не возвращает его факты или память

#### Scenario: Проверка участия недоступна

- **WHEN** Telegram API не позволяет подтвердить текущий статус пользователя
- **THEN** система возвращает безопасный отказ и не использует данные из базы как fallback авторизации

### Requirement: Ошибка определения области данных закрывает доступ

Система MUST NOT расширять область данных при ошибке чтения, разрешения username или проверки источника факта. Ошибка MUST быть наблюдаемой без записи содержимого памяти или факта в лог.

#### Scenario: Не удалось разрешить упоминание

- **WHEN** username не найден или запрос репозитория завершился ошибкой
- **THEN** система не добавляет пользователя и его данные в контекст
