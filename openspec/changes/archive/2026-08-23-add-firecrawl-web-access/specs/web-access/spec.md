## Purpose

Эта capability даёт боту ограниченный доступ к публичному вебу: он может прочитать страницу по ссылке пользователя и найти актуальную информацию с указанием использованных источников.

## ADDED Requirements

### Requirement: Чтение публичной страницы по ссылке

Система MUST предоставлять модели read-only операцию чтения публичного ресурса по абсолютному URL. Результат MUST содержать извлечённый текст, название страницы и URL источника либо безопасное описание ошибки.

#### Scenario: Пользователь просит прочитать рабочую ссылку

- **WHEN** пользователь присылает публичный URL с просьбой прочитать, объяснить или пересказать содержимое
- **THEN** модель получает основной текст страницы и метаданные источника и использует их для ответа

#### Scenario: URL не поддерживается

- **WHEN** URL не является абсолютным `http` или `https` URL либо ресурс недоступен для чтения
- **THEN** web-tool возвращает безопасную ошибку, а бот сообщает о невозможности прочитать ссылку без выдумывания содержимого

### Requirement: Поиск информации в интернете

Система MUST предоставлять модели read-only операцию поиска по непустому текстовому запросу. Результаты MUST содержать ограниченный список источников с URL, заголовком и кратким описанием, если они доступны.

#### Scenario: Пользователь явно просит поискать информацию

- **WHEN** пользователь просит найти информацию в интернете или получить актуальные сведения
- **THEN** модель выполняет web-поиск и использует найденные источники для ответа

#### Scenario: Поиск не дал результатов

- **WHEN** внешний поиск завершился успешно, но подходящих результатов нет
- **THEN** модель получает явное состояние «результаты не найдены» и не представляет отсутствие результатов как найденный факт

### Requirement: Управляемое использование web-tools

Система MUST предоставлять web-tools как read-only инструменты в обычном режиме генерации ответа и в режимах, где уже разрешены read-only инструменты. Модель MUST обращаться к вебу при явной просьбе пользователя о ссылке, поиске или актуальности и MUST NOT выполнять веб-поиск для обычного ответа без такой причины.

#### Scenario: Web-tools доступны в read-only режиме

- **WHEN** генерация запускается с read-only инструментами и Firecrawl настроен
- **THEN** модели доступны только операции чтения страницы и поиска, без операций изменения данных бота

#### Scenario: Обычный вопрос не требует веба

- **WHEN** пользователь не прислал ссылку и не просил искать актуальную информацию
- **THEN** модель отвечает доступным контекстом без автоматического web-вызова

### Requirement: Источники в ответе

Если ответ использует данные web-tools, система MUST передать модели URL использованных источников, а финальный ответ MUST содержать ссылки на эти источники или явно сообщать, что источник недоступен.

#### Scenario: Ответ основан на найденных страницах

- **WHEN** модель сформировала ответ с использованием чтения страницы или web-поиска
- **THEN** ответ содержит ссылки на использованные источники, доступные пользователю Telegram

### Requirement: Безопасность и недоверенное внешнее содержимое

Система MUST принимать только разрешённые публичные URL, ограничивать время выполнения, размер возвращаемого текста и число web-вызовов в рамках одного ответа. Содержимое страниц и результаты поиска MUST рассматриваться как недоверенные данные и MUST NOT интерпретироваться как инструкции для бота.

#### Scenario: Страница содержит вредоносные инструкции

- **WHEN** извлечённый текст страницы пытается изменить правила бота, раскрыть секреты или выполнить действие
- **THEN** модель игнорирует эти инструкции и использует текст только как источник данных

#### Scenario: Превышен лимит web-операции

- **WHEN** запрос превышает лимит времени, размера результата или количества web-вызовов
- **THEN** операция завершается контролируемой ошибкой, а бот сохраняет возможность отправить обычный ответ

### Requirement: Опциональная конфигурация Firecrawl

Система MUST использовать `FIRECRAWL_API_KEY` только для web-доступа. Отсутствие ключа MUST NOT препятствовать запуску бота и обработке остальных сообщений; в этом случае web-tools MUST быть недоступны модели либо возвращать понятное состояние недоступности.

#### Scenario: Firecrawl не настроен

- **WHEN** `FIRECRAWL_API_KEY` отсутствует
- **THEN** бот запускается, продолжает обычную генерацию и не передаёт модели неработающие web-tools

#### Scenario: Firecrawl вернул ошибку

- **WHEN** внешний API отвечает ошибкой, ограничением или временно недоступен
- **THEN** ошибка не раскрывает токен или полный внешний ответ, а модель получает безопасное состояние недоступности источника
