## Why

Бот умеет получать отдельные внешние данные через специализированные tools, но не может прочитать произвольную ссылку от пользователя или найти актуальную информацию в интернете. Доступный токен Firecrawl позволяет добавить оба сценария через уже существующий механизм AI-tools без отдельного браузерного сервиса и без новой базы данных.

## What Changes

- Добавить read-only tool для чтения публичной веб-страницы по URL.
- Добавить read-only tool для поиска информации в интернете.
- Использовать Firecrawl API для извлечения основного содержимого страницы в Markdown и для поиска результатов.
- Разрешить модели обращаться к web-tools, когда пользователь прислал ссылку либо явно просит поискать актуальную информацию.
- Возвращать модели URL и метаданные источников, а в финальном ответе показывать использованные источники.
- Добавить опциональную конфигурацию `FIRECRAWL_API_KEY`; без ключа web-tools не должны ломать запуск и остальные ответы бота.
- Ограничить URL, время выполнения, размер результата и количество web-вызовов на один ответ.
- Не сохранять полный текст страниц, токены и содержимое внешних ответов в обычных логах.
- Не добавлять новую Prisma-модель, отдельную квоту или обязательную npm-зависимость в MVP.

## Capabilities

### New Capabilities

- `web-access`: чтение публичных веб-страниц и поиск информации в интернете через AI-tools.

### Modified Capabilities

Нет.

## Impact

- Затронуты регистрация AI-tools и генерация ответа в `src/ai/`.
- Появится адаптер Firecrawl API и опциональная переменная окружения.
- Изменится поведение модели: она сможет получать недоверенный внешний текст и должна отделять его от инструкций.
- Потребуется покрыть unit-тестами валидацию входа, ошибки Firecrawl, ограничения результата и регистрацию tools в read-only и обычном режимах.
- Внешняя зависимость: `https://api.firecrawl.dev/v2/scrape` и `https://api.firecrawl.dev/v2/search`.
