## ADDED Requirements

### Requirement: Статус typing поддерживается во время распознавания

Если запрос пользователя требует распознавания изображения и бот должен на него ответить, система MUST поддерживать Telegram-статус `typing` от начала подготовки запроса до появления ответа или завершения обработки. Обновления статуса MUST продолжаться во время поиска изображения, проверки квоты и вызова vision API.

#### Scenario: Распознавание фотографии в reply chain занимает много времени

- **GIVEN** пользователь отправил запрос к боту в reply chain с фотографией
- **WHEN** распознавание изображения занимает дольше срока действия одного статуса `typing`
- **THEN** Telegram получает повторные действия `typing` до завершения распознавания или начала ответа
- **AND** отдельное промежуточное сообщение не публикуется

#### Scenario: Пользователь отправил фотографию с запросом

- **GIVEN** пользователь отправил фотографию с подписью, требующей ответа бота
- **WHEN** система ожидает результат распознавания
- **THEN** Telegram получает повторные действия `typing` до появления ответа или ошибки

#### Scenario: Распознавание завершилось ошибкой

- **GIVEN** система уже выставляет статус `typing` для запроса с изображением
- **WHEN** vision API завершился ошибкой
- **THEN** система прекращает дальнейшие обновления `typing`
- **AND** существующая обработка ошибки и возврат квоты сохраняются

#### Scenario: Групповое фото не требует ответа

- **GIVEN** пользователь отправил фотографию в группе без обращения к боту
- **WHEN** система принимает сообщение
- **THEN** система не выставляет и не обновляет статус `typing`
- **AND** изображение не распознаётся
