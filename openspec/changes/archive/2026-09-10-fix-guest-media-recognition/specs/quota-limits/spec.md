## ADDED Requirements

### Requirement: Лимиты IMAGE и VOICE в гостевом режиме

Система SHALL применять квоты IMAGE и VOICE к гостевым запросам так же, как к обычным: сначала групповая квота чата (если есть активная подписка чата), затем персональная квота пользователя. При отказе в квоте система SHALL отвечать коротким русскоязычным текстом через `answerGuestQuery` без кнопки подписки. Дедупликация лимитных уведомлений действует как в обычных чатах.

#### Scenario: Гостевой запрос с фото при доступной квоте

**GIVEN** у пользователя есть доступная квота IMAGE  
**WHEN** гостевой запрос требует распознавания фото  
**THEN** система резервирует квоту IMAGE  
**AND** возвращает `allowed=true`

#### Scenario: Гостевой запрос с фото при исчерпанной квоте

**GIVEN** у пользователя нет доступной квоты IMAGE  
**WHEN** гостевой запрос требует распознавания фото  
**THEN** система отвечает `Лимит анализа изображений на сегодня закончился.` через `answerGuestQuery`  
**AND** vision API НЕ вызывается

#### Scenario: Гостевой запрос с войсом при исчерпанной квоте

**GIVEN** у пользователя нет доступной квоты VOICE  
**WHEN** гостевой запрос требует распознавания аудио  
**THEN** система отвечает коротким русскоязычным текстом об исчерпании лимита через `answerGuestQuery`  
**AND** распознавание НЕ запускается

#### Scenario: Возврат квоты при ошибке в гостях

**GIVEN** квота IMAGE или VOICE зарезервирована для гостевого запроса  
**WHEN** операция распознавания падает с ошибкой  
**THEN** система возвращает зарезервированную квоту  
**AND** счётчик доступных лимитов увеличивается на 1
