# Spec Delta

## MODIFIED Requirements

### Requirement: Вспомогательная модель
Система MUST использовать `openai/gpt-6-luna` с уровнем reasoning `low` для вспомогательных задач генерации, включая обработку изображений, анализ контекста и извлечение сведений. Проверки фактов и псевдонимов моделью решений MUST использовать отдельный decisions-путь.

#### Scenario: Выполняется вспомогательная AI-задача
- **WHEN** вызывается вспомогательная задача генерации
- **THEN** генерация использует `openai/gpt-6-luna` с reasoning `low`

## ADDED Requirements

### Requirement: Модель решений имеет отдельный транспорт
Система MUST использовать Jev через выделенный RouterAI decisions endpoint для проверки фактов и псевдонимов. Запросы MUST использовать существующий ключ RouterAI и фиксированную версию модели; параметры chat-generation MUST NOT передаваться в decisions-запрос. Фактическая модель ответа MUST сохраняться в диагностике.

#### Scenario: Выполняется проверка кандидата
- **WHEN** системе требуется решение Jev
- **THEN** она отправляет state и типизированные вопросы через decisions endpoint и валидирует соответствующие ответы
