# image-recognition Delta Specification

## MODIFIED Requirements

### Requirement: Поиск фото в цепочке reply (multi-hop)

Система SHALL ходить по цепочке reply до maxDepth уровней для поиска изображений. На каждом уровне система MUST проверить медиа текущего сообщения до перехода к родителю или завершения обхода.

#### Scenario: Фото в непосредственном reply

**GIVEN** Пользователь_А отправляет фото с подписью "смотрите"  
**AND** Пользователь_Б отправляет "ио, что это?" как reply на сообщение Пользователя_А  
**WHEN** бот обрабатывает запрос Пользователя_Б  
**THEN** система находит фото в reply_to_message  
**AND** распознаёт изображение  
**AND** бот отвечает с описанием

#### Scenario: Фото через 2 уровня reply

**GIVEN** Пользователь_А отправляет фото с подписью "смотрите чего тут"  
**AND** Пользователь_Б отправляет "интересно" как reply на сообщение Пользователя_А  
**AND** Пользователь_В отправляет "ио, расскажи что это" как reply на сообщение Пользователя_Б  
**WHEN** бот обрабатывает запрос Пользователя_В  
**THEN** система ходит по цепочке: В → Б → А  
**AND** находит фото в сообщении А  
**AND** распознаёт изображение  
**AND** бот отвечает с описанием

#### Scenario: Фото через 3+ уровня reply

**GIVEN** цепочка из 4 сообщений: А(фото) → Б(текст) → В(текст) → Г(запрос "ио")  
**WHEN** бот обрабатывает запрос Г  
**THEN** система ходит по цепочке: Г → В → Б → А  
**AND** находит фото в сообщении А  
**AND** распознаёт изображение  
**AND** бот отвечает с описанием

#### Scenario: Фото находится за пределом maxDepth

**GIVEN** фото находится глубже разрешённого maxDepth в reply chain  
**WHEN** система ищет фото  
**THEN** обход завершается на maxDepth  
**AND** фото не распознаётся

### Requirement: Использование БД для недоступных сообщений

Система SHALL использовать БД (таблицу Message) для получения reply_to_message, если Telegram API не вернул его. Загруженное из БД текущее сообщение MUST быть проверено на фото до проверки наличия `replyToMessageId`.

#### Scenario: reply_to_message доступно через API

**GIVEN** пользователь отправляет запрос с reply на недавнее сообщение  
**WHEN** система ищет фото в цепочке  
**THEN** использует ctx.msg.reply_to_message из Telegram API  
**AND** НЕ обращается к БД

#### Scenario: reply_to_message недоступно через API

**GIVEN** пользователь отправляет запрос с reply на старое сообщение  
**AND** ctx.msg.reply_to_message.reply_to_message отсутствует  
**WHEN** система ищет фото в цепочке  
**THEN** запрашивает replyToMessageId из таблицы Message  
**AND** загружает родительское сообщение из БД  
**AND** проверяет поле media на наличие image/jpeg

#### Scenario: Корневое фото из БД не имеет родителя

**GIVEN** последняя доступная запись reply chain загружена из БД  
**AND** её media содержит image/jpeg  
**AND** её replyToMessageId отсутствует  
**WHEN** система обрабатывает эту запись  
**THEN** она находит фото до завершения обхода  
**AND** использует сохранённое media для распознавания или кэша
