# Design

## Context

Сейчас модели основных и облегчённых ответов объявлены отдельно, а вспомогательная модель задана непосредственно при создании RouterAI-модели. Вызовы моделей сосредоточены в AI SDK и проходят через OpenAI-compatible API RouterAI. См. `proposal.md` и `specs/ai-model-routing/spec.md`.

## Goals / Non-Goals

**Goals:**
- Явно связать каждый из трёх путей генерации с выбранным ID модели и уровнем reasoning.
- Передавать `medium` и `low` для запросов GPT-6 Luna.
- Сохранить квотный выбор основного/облегчённого ответа, инструменты, structured output, аналитические `modelId` и все текущие вспомогательные сценарии.

**Non-Goals:**
- Менять лимиты квот, эмбеддинги, голосовую распознавалку Yandex или промпты.
- Менять выбор модели основного ответа в зависимости от reasoning: для Gemini остаётся уровень по умолчанию.

## Decisions

- Сохранить существующие точки выбора уровней ответа и заменить ID основной и облегчённой моделей в их общем реестре. Это охватывает обычный и гостевой сценарии без дублирования выбора.
- Задать вспомогательную модель централизованно рядом с моделями ответов вместо разрозненных строковых ID. Передавать параметры GPT-6 Luna через `providerOptions` OpenAI-compatible провайдера, используя его `reasoningEffort`.
- Проверить совместно reasoning и уже существующие вызовы инструментов и structured output на RouterAI. Наличие параметров по отдельности не гарантирует поддержку их комбинации; если текущий запросный формат мешает совместимости, адаптировать транспорт в минимальном объёме, сохранив публичное поведение.
- Сохранить текущую запись фактического `modelId` в аналитике и истории ответа, чтобы после замены идентификаторы отражали реально выбранную модель.

## Risks / Trade-offs

- GPT-6 Luna может иначе обрабатывать вызовы инструментов при ненулевом reasoning effort → проверить tool calls и structured output на всех затронутых путях до завершения изменения; при несовместимости скорректировать способ передачи запросов, не снижая зафиксированные уровни reasoning.
- Один и тот же GPT-6 Luna используется с двумя уровнями reasoning → явно закрепить `medium` или `low` в каждом соответствующем пути, чтобы значение по умолчанию провайдера не меняло поведение.

## Migration Plan

Изменение конфигурации моделей и reasoning применяется при следующем запуске приложения. Откат выполняется возвратом предыдущих model ID и удалением новых параметров reasoning; миграция данных не требуется.
