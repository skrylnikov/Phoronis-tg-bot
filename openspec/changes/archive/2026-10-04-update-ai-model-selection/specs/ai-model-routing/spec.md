# Spec Delta

## Purpose

Определяет выбор моделей и уровней reasoning для пользовательских ответов и вспомогательных AI-задач бота. Обеспечивает предсказуемую маршрутизацию при сохранении текущих квот и функций AI.

## ADDED Requirements

### Requirement: Основная модель ответа
Система MUST использовать `google/gemini-3.8-flash` для основного пользовательского ответа, когда квота разрешает основной уровень.

#### Scenario: Квота разрешает основной ответ
- **WHEN** запрос проходит проверку квоты основного уровня
- **THEN** генерация основного ответа использует `google/gemini-3.8-flash`

### Requirement: Облегчённая модель ответа
Система MUST использовать `openai/gpt-6-luna` с уровнем reasoning `medium` для облегчённого пользовательского ответа, когда квота не разрешает основной уровень.

#### Scenario: Используется облегчённый уровень
- **WHEN** запросу назначен облегчённый уровень ответа
- **THEN** ответ генерируется моделью `openai/gpt-6-luna` с reasoning `medium`

### Requirement: Вспомогательная модель
Система MUST использовать `openai/gpt-6-luna` с уровнем reasoning `low` для вспомогательных AI-задач, включая обработку изображений, анализ контекста и извлечение сведений.

#### Scenario: Выполняется вспомогательная AI-задача
- **WHEN** вызывается вспомогательная AI-задача
- **THEN** генерация использует `openai/gpt-6-luna` с reasoning `low`

### Requirement: Совместимость AI-возможностей
Система MUST сохранять существующие структурированные ответы и вызовы инструментов при передаче выбранных моделей и уровней reasoning через RouterAI.

#### Scenario: GPT-6 Luna вызывает инструмент
- **WHEN** облегчённый или вспомогательный запрос требует доступный ему инструмент
- **THEN** RouterAI возвращает корректный вызов инструмента, а обработка завершается по существующему пути

#### Scenario: Запрос требует структурированный ответ
- **WHEN** вспомогательная операция запрашивает структурированный ответ
- **THEN** выбранная модель возвращает результат в ожидаемой схеме
