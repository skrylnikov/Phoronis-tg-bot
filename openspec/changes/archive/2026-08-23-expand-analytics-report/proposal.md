## Why

Текущий вечерний отчёт показывает только базовые счётчики и не позволяет понять, как бот используется в течение дня и какие модели реально отвечали пользователям. Нужен единый отчёт, который можно запросить вручную, а также расширенная аналитика активности, качества контекста и работы AI-пайплайна.

## What Changes

- Добавить скрытую команду `/analytics` для владельца в личном чате.
- Формировать ручной отчёт за текущий день по времени `Europe/Moscow`, не изменяя идемпотентность вечернего отчёта.
- Считать дорогие и дешёвые AI-ответы по фактически использованной модели.
- Сохранять точный идентификатор модели в исходящих AI-сообщениях `Message`.
- Добавить количество аналитик пользователей, увиденных и обслуженных чатов и пользователей, а также найденных фактов.
- Считать количество сообщений, добавленных в prompt из векторного поиска; этот runtime-счётчик обнулять в 00:00 МСК.
- Добавить операционные показатели: успешные и неуспешные ответы, latency, response rate, разбивку по типам чатов и использование фактов через `FactImpact`.
- Сохранить текущие privacy-границы `/ask`; ответы guest mode не смешивать с обычной историей `Message` без отдельного решения.

## Impact

- `src/analytics.ts`, scheduler и новый owner-only controller для ручной команды.
- `src/ai/controllet.ts`, guest/response instrumentation и `src/ai/embedding/index.ts` для runtime-счётчиков.
- `src/repositories/analytics-repository.ts` и запросы к `Message`, `UserFact`, `FactImpact` и `QuotaUsage`.
- `prisma/schema.prisma` и миграция для nullable-идентификатора модели в `Message`.
- Unit-тесты аналитики, авторизации команды, сохранения model ID и сброса векторного счётчика.
- Новые зависимости не требуются.
