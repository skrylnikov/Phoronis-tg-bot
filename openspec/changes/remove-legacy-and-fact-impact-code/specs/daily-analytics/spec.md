## ADDED Requirements

### Requirement: Отчёт содержит только достоверную AI- и пользовательскую аналитику

Отчёт MUST содержать количество дорогих и дешёвых завершённых AI-ответов с разбивкой по точным идентификаторам моделей, количество запусков пользовательской аналитики, количество новых найденных фактов, а также существующие показатели распознавания изображений, голосовых сообщений, покупок, возвратов и активных подписок. Отчёт MUST NOT показывать счётчик использованных фактов, если система не ведёт достоверный источник таких событий.

#### Scenario: Ответы выполнены разными моделями

- **WHEN** в течение дня сохранены ответы, выполненные основной и fallback-моделью
- **THEN** отчёт разделяет их на дорогие и дешёвые и показывает точный `modelId` каждой модели

#### Scenario: Создан новый факт

- **WHEN** в течение дня создан новый `UserFact`
- **THEN** отчёт увеличивает счётчик найденных фактов и не публикует недостоверный счётчик их использования

## REMOVED Requirements

### Requirement: Отчёт содержит AI- и пользовательскую аналитику

**Reason**: Требование обязывает публиковать счётчик использованных фактов, хотя приложение не создаёт достоверные события использования.

**Migration**: Сохранить все подтверждённые показатели, включая новые факты, и удалить только строку и запрос использования фактов.
