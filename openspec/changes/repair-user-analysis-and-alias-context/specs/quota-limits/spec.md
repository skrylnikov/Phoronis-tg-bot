# Spec Delta

## MODIFIED Requirements

### Requirement: Фоновый анализ возвращает квоту до успешного результата

Система MUST считать операцию ANALYSIS успешной только после полного успешного завершения анализа и сохранения его результата. Любая наблюдаемая ошибка MUST переводить durable job в retry либо terminal failure и MUST возвращать зарезервированную ANALYSIS-квоту до следующей попытки. Отсутствие доступной квоты MUST откладывать анализ до следующего периода квоты без AI-вызова, ложного завершения и расходования попытки обработки ошибки; исходное окно MUST сохраняться. Повторная обработка одного source message MUST NOT повторно усиливать уже сохранённый факт.

#### Scenario: Временная ошибка анализа

- **WHEN** модель, база данных или fact analyzer завершают обработку ошибкой после резервирования ANALYSIS-квоты
- **THEN** ошибка не преобразуется в успешный пустой результат, квота возвращается, а durable job остаётся доступной для retry

#### Scenario: Повторная попытка успешна

- **WHEN** retry того же анализа успешно сохраняет результат
- **THEN** ANALYSIS-квота списана ровно один раз за успешную операцию, а job отмечена завершённой

#### Scenario: Ошибка после частичного сохранения

- **WHEN** первая попытка успела сохранить часть фактов и завершилась ошибкой
- **THEN** повторная попытка не увеличивает вес того же факта повторно для того же source message

#### Scenario: Исчерпаны повторные попытки

- **WHEN** durable job достигает terminal failure без успешного анализа
- **THEN** ANALYSIS-квота остаётся возвращённой, а причина отказа доступна в состоянии job и структурированных логах

#### Scenario: При восстановлении квота исчерпана
- **WHEN** восстановленная задача анализа не может зарезервировать `ANALYSIS`
- **THEN** она остаётся доступной для отложенного выполнения с прежним окном, не становится `COMPLETED` и не расходует бюджет error-retry

#### Scenario: Квота снова доступна
- **WHEN** наступил следующий период квоты и отложенная задача выполняется
- **THEN** она резервирует квоту обычным способом и анализирует исходное историческое окно
